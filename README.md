# Sydalesis 6

Free MPE drone / pad synthesizer (VST3, CLAP, and Audio Unit on macOS) by Sydalesis: wavetable, analog, additive,
physical, granular, spectral and FM oscillators.

Music and more: **[sydalesis.bandcamp.com](https://sydalesis.bandcamp.com)**

- **macOS**: universal (Apple Silicon + Intel), macOS 10.15+. See `macos/README-macOS.txt`.
- **Windows**: x64 VST3 / CLAP. Run `install.bat`.

Downloads: see [Releases](../../releases). Every push to `main` also builds both platforms under the **Actions** tab.
